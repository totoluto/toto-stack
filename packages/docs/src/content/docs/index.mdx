## Know what you own

| Framework | Generated application |
| --- | --- |
| Authentication, MFA, sessions and permissions | Your pages, layout and application routes |
| User and account APIs, CSRF and rate limits | Prisma schema, migrations and environment configuration |
| React helpers, lifecycle and service contracts | Docker files and application-specific integrations |

The framework updates through the `toto-stack` package. Files copied by `create-toto-app` belong to your application and remain under your control. [Understand the upgrade boundary](/toto-stack/maintain/upgrading/).
